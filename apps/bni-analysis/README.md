# BNI 分析核心

本模組是富聯會員委員會整合系統中 PALMS 解析、會員對帳、紅綠燈、續約、審計與關懷診斷的唯一規則來源。工作台位於 `../vice-chair`，只能透過版本化分析快照與 `bni-bridge.mjs` 使用結果，不得另寫一套計分邏輯。

## 現行運作位置

- 正式前端由 GitHub Pages 提供；正式會員、原始報表與已發布分析快照存放於 Supabase 受控資料層。
- `engine/` 是可測試的確定性分析核心；分析草稿須經 AI 審視與副主席確認後，才可發布不可改寫的正式快照。
- 本機 `data/`、內部報告及歷史分析是必要的分析工作資料與災難復原資產，受 `.gitignore` 保護，不得推上公開 repository。
- 本機資料不因系統已上線而刪除，但也不自動等同於最新正式資料；只有記錄來源期間、版本／雜湊並完成線上差異核對的副本，才能宣稱可還原。

## 作業入口

修改任何 PALMS、計分、燈號、續約或診斷規則前，先完整閱讀本目錄的 `AGENTS.md` 與 `skill/SKILL.md`，依其中的官方對帳與證據要求執行。

從總專案根目錄使用：

```bash
npm run regression
npm run check
npm start
```

本機儀表板入口為 <http://127.0.0.1:4173/analysis/>。本機預覽只用於開發、驗證、分析與復原演練，不取代正式 GitHub Pages／Supabase 環境。
