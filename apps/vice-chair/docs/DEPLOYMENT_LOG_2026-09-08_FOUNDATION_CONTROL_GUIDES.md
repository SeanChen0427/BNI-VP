# 2026-09-08｜v1.3.3 主選單閃白與地基表單逐步教學

## 範圍

依 Sean 提供的畫面與操作回報，修正地基頁開啟主選單後滑過右側遮罩時變白，並補齊每個地基按鈕、表單欄位與操作邏輯。沿用本任務既有正式發布授權；本版僅前端更新，不部署 app-api、不更動 SQL 或正式會員資料。

- 閃白原因是頁面 `button:hover` 背景蓋過共用遮罩。遮罩明確定義 hover／active 半透明背景及直角，避免染白。
- 新增 `foundation-control-guides.js`：依當下可見欄位及角色，提供新增／調整、卡片各項動作、追蹤紀錄及歷程教學。說明類型、期間、目標、指派、紀錄／確認界線、逐期工作坊、刪除復原與保存取消結果。
- 共用教學引擎支援在既有原生 dialog 內定位，不關閉／重建表單；恢復 inert、展開及捲動狀態，保留未保存輸入。Escape 只暫停教學。歷程資料完成載入才啟用閱讀教學。
- 首次未學過的表單情境可自動教學，之後用表單內教學入口重看；Admin 排除。嵌入續約訪談的地基表單使用同一模組。
- 系統更新獨立頁是本次使用者追加詢問的設計建議，未在本版實作；既有制度課程未變更。
