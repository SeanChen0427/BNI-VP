# LINE 群組與公版訊息

狀態：需求蒐集中  
建立日期：2026-07-11

## 一、新會員宣誓後群組流程

新會員在例會完成宣誓後：

1. 將新會員加入富聯分會各會員群組。
2. 在新會員 LINE 協助群提供「富聯分會－各群組使用說明」。
3. 逐一確認必要群組是否加入成功。
4. 臨時群及領導團隊功能群依會員參與活動或職務加入。
5. 保存說明已發送及會員已確認的日期。

## 二、富聯分會群組清單

| 群組 | 用途 |
|---|---|
| 行政小組群 | 分會分為七個行政小組；組長回報每週組員出席狀況、傳遞資訊及交流 |
| 公告群 | 核心群發布公告；會員已讀即可，不需回應 |
| 交流群 | 大群／交流／聊天、打招呼與歡迎新人，可把名片放相簿；禁止政治、宗教及非本人專業類別推廣 |
| 來賓接龍群 | 會員來賓邀請及報名接龍 |
| 來賓臨時群 | 正式會員常駐；當週來賓入群互動及完成簡報資料，例會後由來賓接待組移除來賓 |
| 培訓接龍群 | 培訓課程報名接龍 |
| 培訓及工作坊臨時群 | 當期培訓資訊佈達 |
| 引薦及感謝單回報群 | 每週例會後開相簿；週二至下週一上傳已 Key 引薦單與感謝單截圖 |
| 一對一回報群 | 每週二由副主席開相簿；週二至下週一上傳一對一照片及表格紀錄 |
| 許願池廣告群 | 生意引薦需求、人脈資源許願及公司活動廣宣 |
| 軟性活動接龍群 | 軟性活動報名接龍；發布前須經核心團隊認可 |
| 領導團隊功能群 | 依職務加入的其他功能群 |

來賓臨時群雖名為「臨時群」，但對正式會員是基礎常駐群；只有來賓是當週加入並於例會後退出或移除。該群主管單位為來賓接待組。培訓／工作坊臨時群及特定活動群才屬條件式加入。

## 三、群組使用說明公版

```text
【 富聯分會-各群組使用說明 】

為了營造正向積極的商務環境，富聯分會所開立的群組中，請避免討論政治、宗教、負面情緒等文字，若列入續約審核。

▲行政小組群：分會將分為七個行政小組，各組會有一名組長，組長會回報每週組員出席的狀況，並向組員傳遞資訊及交流等。

▲公告群：由核心群發佈公告，會員已讀即可，不需在此群做回應。

▲交流群：稱為-大群/交流/聊天群，可用於哈啦、聊天、交流、打招呼、歡迎新人專用(但嚴禁政治、宗教及非本專業以外之推廣)，可將名片放相簿。

▲來賓接龍群：僅限會員來賓邀請報名接龍用。

▲來賓臨時群：用於當週來賓邀約入群及互動，協助來賓完成簡報資料。

▲培訓接龍群：僅限培訓課程報名接龍用。

▲培訓及工作坊臨時群：參與當期培訓資訊佈達臨時群。

▲引薦及感謝單回報群：每週例會後開相簿，週二到下週一，請將key完引薦單及感謝單之後截圖上傳。

▲一對一回報群：每週二副主席開相簿，週二到下週一，一對一拍照回報於當週相簿中。（拿著一對一表格拍照，線上一對一就開一個人的表格分享拍照上傳至相簿）

▲許願池廣告群：僅限尋找生意引薦需求、人脈資源許願及公司活動廣宣用。

▲軟性活動接龍群：用於軟性活動報名接龍用。（發佈前須經核心團隊認可）

■ 其他：各領導團隊功能群。

---
注意：非官方群組如有任何引薦爭議，會員委員會無權督導及處理，請會員懂得自身權益保障！
```

原文中「請避免……若列入續約審核」語句不完整；在 Sean 確認修訂句型前先保留，不自行補寫處分規則。

### 來賓臨時群現行管理補充

- 富聯正式會員長期留在群內，不因例會結束退出。
- 當週來賓依邀約加入，並於當週例會結束後退出或由管理者移除。
- 主管單位是來賓接待組，負責來賓入群、互動、簡報資料協助及例會後移除來賓。
- 副主席在群內常駐並掌握狀態，但不負責日常管理；除非被直接詢問，或事項涉及副主席／會員委員會職責才介入。

## 四、新會員協助群公版

### 訪談排程

```text
我們將安排兩位會員委員與您進行入會訪談，預計全程約需 2 小時。為了確保對談品質，請您預留一段能完整專注、不受干擾的時間。

本次訪談將採線上方式進行，再請您提供幾個方便的時間段，以便為您安排，謝謝！
```

### 訪談完成後轉交導師協調員

```text
感謝【主訪姓名】與【協訪姓名】協助完成本次新會員入會訪談！本階段訪談工作已完成，後續將由導師協調員協助安排新會員導師。

【申請者稱呼】您好，這位是富聯分會的導師協調員【導師協調員姓名】－【專業類別】，接下來將由他／她協助您安排導師。
```

操作順序：確認訪談完成後，先感謝主訪與協訪並將兩人移出協助群，再加入導師協調員並發送介紹訊息。案例中的真實姓名、LINE 標記及專業資料不寫進固定公版。

```text

如果訪談內容沒問題請再幫回覆『訪談內容無誤，已確認！』並加上

姓名：【會員姓名】
身分證號：【身分證號】
```

身分證號是高敏感資料。未來系統應提供受控確認頁面；在仍使用 LINE 時，截圖只交中心區必要人員，不放在一般相簿、AI 知識庫或全體進度總覽。

## 九、董事顧問同意送件

### 續約

傳至三長群：

- 投票結果截圖。
- 訪談內容截圖。
- 該會員一年培訓數。
- 該會員一年來賓數。

### 新會員

傳至三長群：

- 投票結果截圖。
- 訪談內容截圖。
- 不需提供一年培訓及來賓數。

董事顧問回覆同意後，才能勾選「董顧同意」。

## 十、隱私與權限

- 案例姓名、專業別、身分證、個別委員評語、真實投票連結及個人績效數字不進公版。
- 完整委員回饋只供副主席、會員委員會及必要中心區／董事顧問查看。
- 全體委員可見案件進度與回饋完成狀態。
- LINE 截圖需視為案件附件，依保存年限封存或刪除。

### 產生規則

- 沒有本週名單時顯示「無」，不要留下空白。
- 累計級距沒有會員時仍保留該列，或由介面提供「隱藏空級距」選項；正式公告格式由副主席決定。
- 遲到與早退合併計入折算門檻；累計達 3 次時，系統另提示已折算缺席。
- 代理人累計 8 次及缺席累計 3 次應顯示「即將開放」提醒；代理人第 9 次及缺席第 4 次顯示「已達開放專業別門檻」。
- 發布前必須核對會員總人數、兩個到會時間點及各名單人數，避免公告數字與姓名不一致。
- 例會後除文字版出席紀錄外，另附當週點名表截圖。
- 公告用截圖必須排除手機號碼及其他不必要個資，系統應提供安全預覽並阻止含電話的版本直接發布。
- 名牌、PIN 章、西裝／正式服裝及開啟畫面屬商務環境觀察，不是出席或續約審核條件；不得在公告中自動標示為違規或扣分。
