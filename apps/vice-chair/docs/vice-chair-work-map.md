## 新會員專業別判斷圖

```mermaid
flowchart TD
    A["訪談確認實際服務、客群與專業界線"] --> B["辨識與既有會員是否相近／重疊"]
    B --> C{"是否有服務衝突疑慮？"}
    C -->|"無明顯疑慮"| D["仍向相近專業既有會員說明新申請"]
    C -->|"有疑慮"| E["邀請既有會員與申請者共同討論"]
    E --> F{"界線／合作劃分是否獲雙方同意並承諾？"}
    F -->|"是"| G["保留共識與確認紀錄"]
    F -->|"否"| H["以既有會員為主，不予新會員加入"]
    D --> I["繼續委員會回饋、投票、董顧及中心區適用程序"]
    G --> I
    H --> J["整理原因、董顧確認不予入會、通知及退款程序"]
```

案例：土地買賣與北高雄住宅服務可辨識不同定位，但仍與既有會員說明；住宅服務重疊時共同討論界線，不以同為「房仲」直接通過或直接否決。

## 案件下一步圖

```mermaid
flowchart LR
    A["正確案件與指派"] --> B["訪談、表單及 Word 成功保存"]
    B --> C{"案件類型"}
    C -->|"期中／離會"| D["結案並保留紀錄"]

    E --> F["開放投票、確認 Bot 送達及正式票數"]
    F --> G["達參與門檻且有多數結果"]
    G --> H["依案完成會員確認、董顧及中心區適用程序"]
    H --> I["通過或未通過的後續、結案與留存"]
    I --> J["尚有 MSP／地基等承諾仍繼續追蹤"]
```

此圖呈現關卡，正式細節按主題流程。平票不形成決議；未通過分支依案件處理通知與退款等後續，不能照通過分支公告。離會登記與離會訪談彼此獨立。

## 日常判斷的四個問題

1. **到時間了嗎？** 看例行週期、案件期限或個別地基起算日。
2. **誰要做下一步？** 一位主責、適用陪訪及跨職務窗口。
3. **真的完成了嗎？** 看已保存、已發出、已回覆或已核准的實際證據。
4. **後面還有承諾嗎？** 訪談或月會結案，不等於後續工作全部結束。
