# BOD 講解參考文字稿

整理日期：2026-09-09。

**本文件收錄歷任副主席的參考文字稿，不是必須照用的公版。接任者可依自己的語氣、當次議程及需要調整內容、順序與互動方式。**

以下是去識別化整理，已移除舊姓名及場次數據；占位欄位只標示原稿哪些內容需要換成當次資訊，不代表必填模板。編輯加入的主持提示與核對事項均為建議，不是原始文稿或新增制度。已確認的業務程序、正式誓詞與另外提供的 PPT 保密承諾原文，仍按其來源使用。

來源：歷任 BOD 講解留檔。已移除舊姓名、交流次數、交易金額、生態圈／產業鏈數量及互動代碼，以當次欄位替代，不另保存含舊個案數據的原稿。

本稿用於 BOD 講解，沿用原留檔的場合名稱；不自行推定 BOD 全名、固定頻率、報告月份或投影片架構，也不併入每週例會報告或月度 Power of One 報告。

## 一、留檔的表達順序（供參考）

1. 自我介紹與回顧期間。
2. 說明會員商務交流成果，連結到了解彼此生意與轉介紹的價值。
3. 說明同期間的交易金額，與現場互動。
4. 以「不可能變可能」「下一個夢幻引薦」鼓勵參與。
5. 介紹當期生態圈及產業鏈，連結人脈、資源與合作機會。
6. 邀請大家一起串聯資源、創造價值。

## 二、參考文字稿（去識別化整理）

「【】」是當次需填欄位，「〔〕」是主持提示，不念出。

```text
大家好，我是本屆副主席【副主席姓名】。

時間真的好快！回顧【統計期間】，
會員間的商務交流次數達到了【商務交流次數】次。
每一次交流，都讓我們更了解彼此的生意，
也更能為夥伴帶來轉介紹的機會。

透過深度的商務交流，我們在這段期間創造出【交易金額】的交易成果。

如果你覺得這樣的金額，在你目前的行業中幾乎不可能實現，
請在聊天室打上【當次互動代碼】！
〔留出時間讓現場回應。〕

在富聯，我們一起突破了這個極限，證明不可能變可能。
我相信，下一個夢幻引薦，就是你！

目前富聯擁有【生態圈數量】大生態圈、【完整產業鏈數量】條完整產業鏈，
從資源串聯到商務合作，打造出強大的生態系。

不論你需要的是人脈、資源還是成長機會，
富聯都能成為你最堅實的後盾。

讓我們一起攜手，串聯更多可能，創造無限價值！
```

本參考稿保留原稿的鼓勵語氣。實際成果與「完整產業鏈」等描述須依當次資料核對；未確認的數字或狀態先補齊，或改寫為有依據的說明，不照念占位文字。

## 三、使用前替換與核對

| 欄位 | 準備與核對方式 |
|---|---|
| 副主席姓名 | 使用實際當屆姓名 |
| 統計期間 | 明列起訖；舊稿回顧一年，不表示每次都固定一年 |
| 商務交流次數 | 核對來源與上述期間 |
| 交易金額 | 核對來源、幣別、單位與期間；口語概數須有原始數據依據 |
| 當次互動代碼 | 依當次活動設定；未安排聊天室互動時，刪除該互動段並調整銜接 |
| 生態圈數量 | 核對當期分會資料及資料日期 |
| 完整產業鏈數量 | 同時核對數量與是否確實符合當期所稱「完整」，不沿用舊稿描述 |

數據及生態圈資訊於每次使用前核對；不把這份歷史稿當成正式分析資料來源，也不因整理文案改動系統統計。

## 四、自行準備時的核對建議

- [ ] 已依當次 BOD 安排確認使用這份稿件。
- [ ] 姓名、回顧期間、交流次數與交易金額已更新核對。
- [ ] 生態圈及完整產業鏈的數量與描述有當期依據。
- [ ] 若配合簡報，文字稿、數字及畫面一致；本次未取得或推定 BOD 固定 PPT 架構。
- [ ] 互動方式與代碼符合當次安排，已預留回應時間。
- [ ] 所有未填欄位及不使用的提示已清除，已試讀銜接。
