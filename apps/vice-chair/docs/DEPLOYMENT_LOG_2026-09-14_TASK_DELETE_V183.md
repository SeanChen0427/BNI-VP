## 原因與修正

新增工作的指派歷程使用 `task_id ON DELETE SET NULL`；歷程的全面禁止 UPDATE trigger 把資料庫自動解除外鍵也擋住，導致 `AUDIT_HISTORY_IMMUTABLE` 並回滾工作刪除。

`20260914100000_fix_task_history_delete_cascade.sql` 改用指派歷程專用 trigger：只允許巢狀觸發、原工作已不存在、`task_id` 從非空變空且其他全部欄位相同的 UPDATE。歷程內容、操作者、時間及永久工作識別碼保留；其他 UPDATE／DELETE、已完成工作、已結案案件及換屆事件保護維持有效。
