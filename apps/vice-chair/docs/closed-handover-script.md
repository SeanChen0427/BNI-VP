# 封閉交接參考文字稿：任期目標、委員介紹與保密承諾

整理日期：2026-09-09。

**本文件收錄歷任副主席的參考文字稿，不是必須照用的公版。接任者可依自己的語氣、當次議程及需要調整內容、順序與互動方式。**

以下是去識別化整理，已移除舊姓名及場次數據；占位欄位只標示原稿哪些內容需要換成當次資訊，不代表必填模板。編輯加入的主持提示與核對事項均為建議，不是原始文稿或新增制度。已確認的業務程序、正式誓詞與另外提供的 PPT 保密承諾原文，仍按其來源使用。

來源：封閉交接參考留檔，以及 PPT 內「會員委員會保密承諾」原文。

記錄過往封閉交接副主席環節的安排：說明任期目標、介紹委員，再帶領保密承諾。新任自行設定目標，主持語氣與銜接可自行調整。

「【】」是當次填寫欄位，「〔〕」是主持提示，不念出。當屆名單及專業別於受控的實際工作稿填寫，本參考稿不預填真實人名。

## 一、先分清楚哪些要換、哪些保留

| 內容 | 新任副主席準備方式 |
|---|---|
| 本屆任期目標 | 由新任副主席自行設定，依實際目標調整項數與文字 |
| 委員介紹 | 使用當屆名單，逐位念出姓名與目前登錄的專業別 |
| 保密承諾 | 使用下方 交接提供的 PPT 原文，核對投影片與文字一致 |
| 主持銜接 | 可依說話方式調整，保留邀請全體委員開麥及共同宣讀的提示 |

### 舊任目標僅供歷史參考

以下是過往任期的目標設定，不是下一屆固定目標：

> 1. 執事四大專員分工作業
> 2. 持續落實363關懷計畫
> 3. 分會整體保留率提升至80%

歷史原文保留「執事」稱呼；現行參考稿統一使用「會員委員」。新任不必沿用四大專員配置、這組目標或 80% 數字，也不把三項當成固定目標數量。目標由新任自行設定；既有會員作業與權限仍依現行流程執行。

## 二、參考文字稿（去識別化整理）

```text
接下來向大家說明本屆會員委員會的任期目標。

【逐項說明由新任副主席自行設定的任期目標。】

接著介紹本屆的會員委員會夥伴。

【委員姓名】，專業別是【該委員的專業別】。
〔依當屆名單逐位介紹，確認姓名與專業別對應正確。〕

在這個特別的時刻，也請所有會員委員開啟麥克風，
一起宣讀保密承諾。
這是我們會員委員會對於分會的承諾與責任！

〔切換到「會員委員會保密承諾」投影片，確認委員準備好後，共同宣讀下方原文。〕
```

## 三、PPT 原文：會員委員會保密承諾

以下正文保留 交接提供的原文，只整理貼上造成的空白與段落。

```text
【會員委員會保密承諾】

會員委員會討論的所有內容都被視為機密資料，並且要嚴密保存在會員委員會內部。

守密可以讓會員覺得安全，並且讓分會組織發展更好，當處理具有挑戰性的人際關係時是讓人不太舒服的，需具有很強紀律性的會員委員會才會有機會成為成功的團隊。

本人願意遵守會員委員會之保密規範，若有違反，經查屬實自願離開分會以示負責。如果涉及相關法律，亦由本人承擔。
```

〔宣讀完成後，依當次封閉交接議程銜接下一環節。〕

本次提供的是保密承諾，不是新會員／續約會員的入會宣誓詞；兩種文稿分開使用。此處保存提供的承諾文案，不新增系統自動離會、撤權、投票或處置功能，也不更動既有正式案件送審與權限流程。

## 四、上台前核對建議

- [ ] 任期目標已由新任自行設定，PPT 沒有誤留舊任目標或舊數字。
- [ ] 當屆委員名單完整，姓名、專業別與介紹順序已核對。
- [ ] 當次工作稿所有占位欄位都已填妥，沒有混入上一屆名單。
- [ ] 「會員委員會保密承諾」投影片與本文件原文一致。
- [ ] 委員知道共同宣讀時需要開啟麥克風。
- [ ] 已試讀「目標 → 委員介紹 → 開麥 → 保密承諾」的銜接。
- [ ] 宣讀後依當次議程銜接下一環節。

上述檢核是交接操作建議；實際宣讀狀態須在當次執行後確認，不能把準備好參考稿當成委員已完成承諾。
