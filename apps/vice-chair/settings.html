三層權限

權限固定，不追加更細角色

系統開發人員 Admin

管理帳密、指定副主席、增減委員與系統維護。

共用委員帳密；登入選姓名後填寫回饋、投票與執行任務。

06

三家 API Key 申請教學

依官方頁面操作；Key 建立後只貼回上方對應欄位

GPT／OpenAI約 3–5 分鐘
  1. 登入 OpenAI Platform。
  2. 進入 API Keys，建立新的 Secret Key。
  3. 如尚未啟用 API 計費，依頁面設定 Billing／Credits。
  4. 複製 Key，貼到上方 OpenAI 欄位並儲存。
開啟 OpenAI API Keys 官方頁面 →
Gemini／Google約 3–5 分鐘
  1. 登入 Google AI Studio。
  2. 開啟 API Keys，選擇或建立 Google Cloud 專案。
  3. 建立 Gemini API Key；新 Key 建議使用官方目前提供的受限／授權金鑰。
  4. 複製 Key，貼到上方 Gemini 欄位並儲存。
開啟 Google AI Studio API Keys →
Claude／Anthropic約 3–5 分鐘
  1. 登入 Anthropic Console。
  2. 確認 API 帳戶已有可用額度或計費方式。
  3. 進入 API Keys 建立新的金鑰。
  4. 複製 Key，貼到上方 Claude 欄位並儲存。
開啟 Anthropic Console API Keys →

API Key 等同密碼。不要貼到 LINE 群組、Google 文件、GitHub、截圖或交接文件；疑似外洩時請立即至原平台撤銷並重建。
